## Deduplication policy

A posting is considered a duplicate when it has the same employer and requisition/job ID. When no ID is available, the tracker compares the normalized employer and role title. The entry with the more complete official link and details is retained.

## Accuracy policy

- Job titles in the table link directly to the official application page.
- Dates use the `Month Day, Year` format.
- Missing information is shown as **Not listed**, not guessed.
- Estimated hourly rates derived from monthly, weekly, or annualized pay are labeled **Est.**
- Estimated total compensation uses 40 hours per week and excludes unlisted bonuses, benefits, equity, and housing.
- U.S. work authorization is not treated as the same thing as U.S. citizenship.
