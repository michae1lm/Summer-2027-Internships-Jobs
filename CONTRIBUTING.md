# Contributing

Submit a pull request that updates both:

- `data/opportunities.csv`
- `data/opportunities.json`

Required fields:

- Company
- Exact role title
- U.S. location
- Official application URL
- Status
- Opening date if stated
- Closing date if stated
- Work authorization/sponsorship language
- Citizenship requirement only if explicitly stated
- Clearance requirement only if explicitly stated

Do not guess missing information. Use an empty value and explain it in `source_note`.
